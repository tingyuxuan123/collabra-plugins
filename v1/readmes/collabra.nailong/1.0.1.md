# 奶龙（Collabra 适配版）

奶龙主题的 Collabra 适配版：浅色是奶油底配巧克力棕字，深色是巧克力夜配奶龙黄。
主题键 `collabra.nailong/nailong`，插件 id `collabra.nailong`。

社区收录（`tier: community`），**不是**角色权利方的官方插件。角色图、动效、字标和
图标沿用上游 `enso.nailong` 0.1.2 的原始素材（逐字节未改），只把 CSS 挂点适配到
Collabra 当前布局。来源与核对方式见 `NOTICE.md`。

## 装的是什么

- 一整套调色板（浅色 / 深色各九个色位），映射到 Collabra 的语义颜色令牌。
- 一份**全局 CSS**：`themes/nailong.css` 会注入主窗口的界面样式（画布斑点、侧栏、
  输入框探头、思考头、代码块小脸、待办、状态行、右侧面板角落、用户气泡、选中色）。
- 角色图与动图都来自本包 `themes/assets/`，不联网、不外链。

## 权限与安全

- 插件 `permissions` 为空数组，没有 `main` / `renderer` 入口。
- 安装与运行都不执行插件 JavaScript、不装依赖、不发网络请求、不读本机任意路径；
  样式里的相对 `url()` 只会解析到本包内的文件。
- 因为要改写界面样式，Collabra 会在安装/更新时单独请求「修改界面样式」授权
  （由 `contributes.themes[].css` 派生，不是额外权限项）；不授权则主题不可用。
- 全局作用范围只有样式：不改应用设置、不改字体与根字号、不改全局圆角。

## 安装后怎么用

1. 在市场里安装本插件，并在权限摘要里确认「修改界面样式」。
2. 打开 **设置 → 外观 → 主题**。已启用的插件主题会以卡片形式出现在内置主题旁边。
3. 点 **奶龙** 卡片才会切换到这个配色；**安装本身不会切换主题**，之前选的
   云白 / 薄荷白 / 深色等设置保持不变。
4. 想换回去：点任一内置主题卡片即可，插件不写你的浅色方案。

与旧的 `enso.nailong`（不同插件 id、不同主题键）可以并存：两张主题卡各自独立，
装这个不会覆盖、卸载或改写旧插件与其设置。

## 适配改了什么

上游 0.1.2 是给旧宿主写的，直接搬过来会失效或误伤，因此：

- 删掉 `@font-face` 与 `:root{--font-family-sans}`：不再替换宿主字体，也不再分发
  自带的 `rounded-medium.woff2`（已无引用）。
- 删掉 `:root{--radius: 0.875rem}`：不再覆盖全局圆角。
- 失效挂点按 Collabra 真实 DOM 重写，例如 `status-line` → `data-slot="stats-line"`、
  思考动画改用宿主 `data-live`、输入框探头改挂 `[data-enso="composer"]`
  （旧的 `.enso-chat-col > :first-child` 会命中时间线每一行，已弃用）。
- 空态角色图从 `[data-enso="main"]` 移到「有对话但还没消息」的空时间线，并加
  `[data-slot="chat-view"]` 护栏，扩展页 / 设计画廊 / 侧栏 BTW 不会被角色图污染。
- 装饰全部 `pointer-events: none`，尺寸随视口与字号收缩。

## 紧凑窗口：先保正文

小窗口（逻辑视口高 ≤ 680px 或宽 ≤ 960px）里，输入框上方的角色头会压住时间线最后
一条正文；`pointer-events` 只能保证点得到，不保证读得到。因此命中该条件时用
`content: none` 收起三处会盖住正文的大装饰：输入框外探头、右侧面板右下角大图、
空时间线的角色大背景与欢迎动图。侧栏角色、思考头、代码块小脸、待办、状态行小脸
仍然保留。素材文件没有删除，只是在这个尺寸下不画；宽屏行为不变。

## 兼容与实测范围

兼容范围（市场筛选依据）：

- Host `collabra`；市场 API `1`；最低应用版本 `0.2.81`。`0.2.81` 是市场协议与市场身份
  接入的首个版本，低于它的客户端读不到本市场；主题 CSS 本身没有用到该版本之后的新 API。
- 平台声明 macOS（`darwin`）与 Windows（`win32`）：本包是纯 CSS + 包内图片，没有
  `main` / `renderer` 入口、不联网、不读绝对路径、不依赖 macOS 专有字体或路径，因此两个
  平台走同一套 Electron 主题运行时。Linux 未请求也未验证，不在兼容声明里。

验收范围（只写真实做过的）：

- 视觉验收只在 macOS 真机上做过：逐页看过 Code 对话、设置、Bot，所以
  `testedSurfaces` 只声明这三项；图片工作室、任务看板、独立设计窗口未逐页验收。
- Windows 只验证了包目录结构、资源逐字节一致与市场平台筛选（`win32` 能选中本版本）；
  **没有**在 Windows 真机上做过界面视觉验收，观感可能与 macOS 有差异。

## 卸载

先切换到其他主题，再到扩展页移除本插件；移除后恢复之前选择的 Collabra 主题。
