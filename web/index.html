Install

从 ZIP 安装

  1. 01

    下载 ZIP

    在上面的目录中选择插件，下载对应版本的 ZIP 包。下载不会自动安装。

  2. 02

    在 Collabra 扩展页安装

    打开 Collabra 的扩展页面，选择「添加扩展」→「从 ZIP 安装」，选中刚下载的文件。请先阅读权限与兼容性摘要。

  3. 03

    确认并启用

    只有在你确认安装后，插件才会写入应用私有目录。本市场不会使用自定义 URL 协议，也不会绕过安装确认。

Trust

签名、完整性与边界

签名索引

v1/index.json 的原始字节由 Ed25519 私钥签名。Collabra 客户端只信任仓库内置的生产公钥，并拒绝更旧的 sequence。

版本不可变

同一个 (插件, 版本) 的包字节与兼容性字段一经发布不可修改。 修复必须发布新版本；下架只会停止索引，不删除历史 ZIP。每代还保留签名的 索引快照与 artifact ledger，用于校验已下架包的哈希和旧版本 README。

有界且不执行

发布流程不执行插件入口、生命周期脚本或 npm install。包必须自包含， 拒绝符号链接、硬链接、原生模块、特殊文件与路径越界；最多 5000 个文件、 200MB。

诚实的测试范围

插件只在真实验证过的界面上声明 testedSurfaces。 调色板可用不等于所有界面已验收；空列表是诚实状态，不是缺失营销文案。

审批边界

CI 只校验结构、权限、打包与签名，不判定插件 tier。标记为「官方精选」需要 维护者通过受保护的 main 分支和 CODEOWNERS 审查确认；CI 本身不会自动授予 或阻止社区作者自填 tier。

许可证范围

平台代码与内置 Collabra Paper 采用 MIT；第三方插件以目录卡片中显示的各自 License 为准，本站的 MIT 徽标不覆盖第三方插件。
