# Collabra Paper

An original, neutral paper palette for Collabra. It ships two matched palettes,
light and dark, and nothing else: no JavaScript entry, no remote assets, no
network access and no decorative artwork.

## What it changes

The theme supplies the nine palette slots Collabra themes support: canvas,
surface, sunken, border, borderStrong, text, textMuted, textSubtle and accent.
It does not add CSS, so it cannot restyle components beyond those slots.

## Install from the market ZIP

1. Download the 1.0.0 ZIP from the Collabra market page.
2. In Collabra, open **Extensions** (扩展), choose **Add extension** and install
   from the downloaded ZIP.
3. Review the permission summary. This plugin requests no permissions.
4. Open the theme picker and select **Paper**.

The ZIP is self-contained. Installation does not run npm, install
dependencies, or execute plugin JavaScript.

## Compatibility and honest test coverage

- Host: `collabra`
- Market API: `1`
- Minimum app version: `0.2.80`
- Platforms declared: macOS, Windows, Linux
- Tested surfaces: none declared

The package has been validated by the publisher (manifest, palette JSON,
archive integrity and bounded contents). No chat, bot, image-studio, taskboard,
design or settings surface has been manually verified, so `testedSurfaces` is
intentionally empty. Palette support is not the same as verified decorative or
surface coverage.

## Uninstall

Choose another theme, then remove the extension from the Extensions page.
Removing it restores the previously selected Collabra theme.
